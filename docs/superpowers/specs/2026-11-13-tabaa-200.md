# Tabaa: 200 templates and similar-template search

Omar asked (2026-11-13) for at least 200 templates with no repeats: every
template a new idea and a different design. He also wants a "similar
templates" search before editing, like Naqsh has. He chose both uses of
similarity (a row for visitors and a no-repeat test) and new categories as
well as growing the current ones.

## Similarity

- `scripts/similar.ts` embeds every thumbnail with CLIP
  (`Xenova/clip-vit-base-patch32` through `@huggingface/transformers`, the
  model the catalogue repo already uses; cached in `.models/`, git-ignored).
- It writes `src/templates/similar.json`: for each template id, the 8 closest
  other templates by cosine similarity, and the score of the closest pair.
- The template page shows "قوالب مشابهة" above the edit fields (replacing the
  "more in this category" row at the foot), so a visitor can jump before
  typing anything.
- `tests/similar.test.ts` fails when any two templates score above the
  repeat threshold (set from the measured spread of the current 60), and when
  similar.json is missing an id or is older than the registry.
